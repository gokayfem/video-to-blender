# Controls

The `Storybook Street` modifier panel, generated by `tools/graph_doc.py` from the built file. Defaults are the reference look. Colours are shown as sRGB.

## Primary

| Control | Default | Range | What it does |
|---|---|---|---|
| Path |  |  | The curve the street follows. Draw any curve and pick it here |
| Seed | 0 |  | Changes every random choice: house widths, colours, props, stones |
| Street Width | 3 | 1 – 20 | Curb-to-curb width of the cobbled road |
| Extra Storeys | 0 | -2 – 4 | Taller or lower houses: added to Storeys Min and Max |
| Timber Amount | 1 | 0 – 1.7 | 0 = plain plaster houses, 1 = the reference, more = busier framing |
| Prop Amount | 1 | 0 – 2 | Scales every prop chance: window boxes, awnings, signs, lanterns, pots, barrels, ivy |
| Flower Amount | 1 | 0 – 3 | Blossoms in window boxes and flowers in the grass |
| Festivity | 1 | 0.2 – 3 | More bunting strings and paper lanterns (hide them with Show Bunting) |
| Wind | 1 | 0 – 8 | 1 = the reference's light breeze; 4-6 = a windy day (bunting, signs) |
| Walk Speed | 0.9 | 0 – 5 | Walking speed in H (walker heights) per second |
